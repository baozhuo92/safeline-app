#  配色方案设计文档

> 版本：v1.0 | 日期：2026-05-07

本文档定义App 的完整色彩体系，包含两套可选品牌色方案（淡绿色 / 橙色），以及对应的功能色、中性色和暗色模式适配。

## 3. 使用原则

### 3.1 按钮颜色

| 按钮类型 | 背景色 | 文字色 | 边框 |
|----------|--------|--------|------|
| **主按钮** | 品牌色 500 | 白色 | 品牌色 600 |
| **主按钮悬浮** | 品牌色 400 | 白色 | — |
| **主按钮按下** | 品牌色 600 | 白色 | — |
| **主按钮禁用** | 品牌色 200 | 品牌色 400 | — |
| **次按钮** | 透明 / 白色 | 品牌色 500 | 品牌色 500 |
| **危险按钮** | `#EF4444` | 白色 | `#DC2626` |
| **文字按钮** | 透明 | 品牌色 400 | 无 |

### 3.2 标签 / Badge

| 类型 | 背景 | 文字 |
|------|------|------|
| 默认标签 | 品牌色 100 | 品牌色 700 |
| 成功标签 | `#ECFDF5` | `#047857` |
| 警告标签 | `#FFFBEB` | `#B45309` |
| 危险标签 | `#FEF2F2` | `#B91C1C` |
| 信息标签 | `#EFF6FF` | `#1D4ED8` |

### 3.3 Toast / 消息条

| 类型 | 背景 | 图标色 | 边框 |
|------|------|--------|------|
| 成功 | `#ECFDF5` | `#10B981` | `#A7F3D0` |
| 警告 | `#FFFBEB` | `#FBBF24` | `#FDE68A` |
| 错误 | `#FEF2F2` | `#EF4444` | `#FECACA` |
| 信息 | `#EFF6FF` | `#3B82F6` | `#BFDBFE` |

### 3.4 对比度检查

| 场景 | 前景 | 背景 | 对比度 | WCAG |
|------|------|------|--------|------|
| 主按钮文字 | 白 `#FFF` | 品牌色 500 | 2.2:1 | 需文字加粗（≥14px bold 即合规） |
| 正文 | `#111827` | `#FFFFFF` | 16.7:1 | AAA 通过 |
| 次要文字 | `#6B7280` | `#FFFFFF` | 5.9:1 | AA 通过 |
| 占位文字 | `#9CA3AF` | `#FFFFFF` | 3.0:1 | 不适用 placeholder 豁免 |
| 暗色正文 | `#F9FAFB` | `#1C1610` | 14.5:1 | AAA 通过 |
